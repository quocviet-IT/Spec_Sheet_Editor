# M4b Editor Tools Implementation Plan

> Work through the tasks in order. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the editor (S4): read a value the scan missed by clicking it (UC-06), draw a box
around a value the machine cannot read and choose its angle (UC-07), offer to apply a change where the
same old value appears elsewhere (UC-05 5a), rename the sheet (F-06), tell the person precisely why the
value reader could not start, and prove the drawing with pixel tests (TC-30, TC-31, TC-36).

**Architecture:** One OCR client per open sheet, owned by a `useValueReader` hook: it starts once (the
first detection, a click, or an idle warm-up), holds the page, and stops when the page closes. Worker
failures carry a typed code (`model_download`, `runtime_download`, `init_failed`, `bad_request`,
`failed`) so the editor can say "check your connection" or "this browser cannot run it". Pure helpers
in `src/editor/` turn a drawn rectangle and a chosen angle into a text box, find the value under a
point and the other places showing the same old value. The save action also stores the name.

**Tech Stack:** as M4a — Next.js 16.3.8, React 19.2, Tailwind CSS 4, Supabase (`save_sheet`), the M2 OCR
Worker (onnxruntime-web 1.30), Zod 4, Vitest 4, Playwright 1.63, pdf-lib 1.17.1 (synthetic files only).

**Spec:** `docs/design/spec-sheet-editor-design.md` — UC-04 exception 3a, UC-05 extension 5a, UC-06,
UC-07, UC-08 (rename), F-06, F-10, F-11, F-14, NFR-01 (read on click ≤ 5 s), NFR-07, section 8.4
(`K` = Draw box), Table B.1; test cases TC-24, TC-25, TC-30, TC-31, TC-32, TC-34 – TC-36. Roadmap M4b
(`docs/plans/2026-10-07-spec-sheet-editor-roadmap.md`), and the M4a items carried into M4b there.

## Global Constraints

- Repo is **public**: never commit `.env.local`, real sheets, SO/MO numbers, passwords or keys. Test files are synthetic and generated by code. Stage files one by one (`git add <path>`), never `git add -A` or `git add .`.
- File names, commit messages and documents are in English. The only Vietnamese text in the repository is interface copy: `src/messages/vi.ts` and the language's own name ("Tiếng Việt") on the VI/EN switch (end-to-end tests may match the Vietnamese interface text in regular expressions, as the existing specs do).
- Commits carry no attribution trailer of any kind (no Co-Authored-By, no tool or AI mentions).
- Code, identifiers and comments in English.
- Every user-facing string comes from `src/messages/vi.ts` + `src/messages/en.ts`; both keep exactly the same keys.
- Every data-bearing page, server action and route handler calls `requireUser()` / `requireAdmin()` itself.
- Sheet images travel only between the browser and the company's Supabase Storage (NFR-03).
- The original file is never changed (BR-03): edits are data drawn over the original.
- Positions (design 6.3) are fractions of the trimmed page: `cx` of the page width, `cy` of the page height, `w`, `h` and `Edit.fontPx` of the page width. `angle` is the reading direction in degrees with y pointing down (the canvas `rotate()` angle): 0 left to right, −90 bottom-up, 90 top-down; stored angles lie in (−180, 180].
- Drawing area (BR-02): x 0.046 – 0.670, y 0.133 – 0.746 of the trimmed page. A value belongs to the drawing when its centre lies inside it; a drawn box must lie wholly inside it (UC-07 1a).
- Read on click (UC-06): a square 5.6 % of the page width on each side around the click, up to 5 seconds or all angles; then "No value could be read here. Use Draw box to mark it."
- Draw box angles (UC-07): Horizontal, Vertical up, Vertical down, Free rotation (degrees).
- Matching values (UC-05 5a): only values not yet edited whose machine reading equals the confirmed old value; applied only when the person accepts.
- The editor needs a window at least 1024 px wide (NFR-06). Interface tokens: detected `--mark`, edited `--edit`, errors `--danger`.
- Applied migrations are never edited (M4b adds none). `DATABASE_URL` points at the development project only.
- End-to-end tests always have timeouts (test, expect, global), run against the development project only (`E2E_DEV_PROJECT_REF` guard), clean up what they create and use only the reserved accounts `e2e-staff@ctyhp.vn` and `e2e-staff-b@ctyhp.vn`.

In `src/editor/detections.ts`:

```ts
import { OcrFailure } from "@/lib/ocr/protocol";

export type OcrLike = Pick<OcrClient, "scan">;
export type ReaderFailure = "ocr_load" | "ocr_unsupported";
export type DetectResult =
  | { ok: true; source: "pdf-text" | "ocr"; detections: Detection[] }
  | { ok: false; reason: ReaderFailure | "ocr_scan" | "cancelled" };

/** A download that failed is a connection problem; a runtime that cannot start is the browser's. */
export function ocrFailureReason(error: unknown): ReaderFailure {
  return error instanceof OcrFailure && error.code === "init_failed" ? "ocr_unsupported" : "ocr_load";
}

/**
 * UC-04: the text layer when it has values in the drawing area, otherwise a scan of the drawing area by
 * the page's reader (models loaded, page set). `isCancelled` stops before the scan when the page closed
 * while the reader was starting.
 */
export async function detectValues(
  page: LoadedPage,
  getReader: () => Promise<OcrLike>,
  newId: () => string = () => crypto.randomUUID(),
  isCancelled: () => boolean = () => false,
): Promise<DetectResult> {
  const fromText = fromPdfText(page, newId);
  if (fromText.length > 0) return { ok: true, source: "pdf-text", detections: fromText };
  let reader: OcrLike;
  try {
    reader = await getReader();
  } catch (error) {
    return { ok: false, reason: ocrFailureReason(error) };
  }
  if (isCancelled()) return { ok: false, reason: "cancelled" };
  try {
    const scan = await reader.scan(drawingAreaPx(page.raster.width, page.raster.height));
    return { ok: true, source: "ocr", detections: fromScan(scan, page.raster, newId) };
  } catch {
    return { ok: false, reason: "ocr_scan" };
  }
}
```

- [ ] **Step 4: One reader per open sheet**

`src/app/(app)/sheets/[id]/use-value-reader.ts`:

```ts
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import { ocrFailureReason, type ReaderFailure } from "@/editor/detections";
import { DEFAULT_MODELS, OcrClient } from "@/lib/ocr/client";
import type { Raster } from "@/lib/ocr/raster";

export type ReaderState = "idle" | "loading" | "ready" | ReaderFailure;

/**
 * The page's OCR reader (UC-04 scan, UC-06 read on click): started once, on first need, with the models
 * loaded and the page set; stopped when the page closes. A start that failed is forgotten, so the next
 * need tries again with a new Worker (onnxruntime cannot initialise twice in one Worker). `ensure` takes
 * the page raster, because the first detection asks for the reader in the same tick the page is loaded.
 */
export function useValueReader(): { state: ReaderState; ensure: (page: Raster) => Promise<OcrClient> } {
  const client = useRef<OcrClient | null>(null);
  const starting = useRef<Promise<OcrClient> | null>(null);
  const alive = useRef(true);
  const [state, setState] = useState<ReaderState>("idle");

  useEffect(() => {
    alive.current = true;
    return () => {
      alive.current = false;
      client.current?.dispose();
      client.current = null;
      starting.current = null;
    };
  }, []);

  const ensure = useCallback((page: Raster): Promise<OcrClient> => {
    if (starting.current) return starting.current;
    setState("loading");
    const start = (async () => {
      const fresh = new OcrClient(); // inside the async function: a Worker that cannot be built rejects
      try {
        await fresh.init({ det: DEFAULT_MODELS.det, rec: DEFAULT_MODELS.rec, keys: DEFAULT_MODELS.keys });
        await fresh.setPage(page);
      } catch (error) {
        fresh.dispose();
        throw error;
      }
      if (!alive.current) {
        fresh.dispose();
        throw new Error("The page was closed.");
      }
      client.current = fresh;
      setState("ready");
      return fresh;
    })();
    starting.current = start;
    start.catch((error: unknown) => {
      if (starting.current === start) starting.current = null;
      if (alive.current) setState(ocrFailureReason(error));
    });
    return start;
  }, []);

  return { state, ensure };
}
```

The reader always holds the page it was started with; the editor shows one page for its whole life, so
it is never asked for another.

/** A drag from one corner to the other, in either direction. */
export function rectFromDrag(a: Point, b: Point): Rect {
  return { x: Math.min(a.x, b.x), y: Math.min(a.y, b.y), w: Math.abs(a.x - b.x), h: Math.abs(a.y - b.y) };
}

/** A drag shorter than this on either side (page pixels) is a click, not a box. */
export const MIN_DRAWN_PX = 4;

/** UC-07 exception 1a: every corner of the drawn rectangle lies inside the four panels. */
export function rectInDrawingArea(rect: Rect, pageW: number, pageH: number): boolean {
  return (
    rect.x >= DRAWING_AREA.x0 * pageW &&
    rect.y >= DRAWING_AREA.y0 * pageH &&
    rect.x + rect.w <= DRAWING_AREA.x1 * pageW &&
    rect.y + rect.h <= DRAWING_AREA.y1 * pageH
  );
}

/** UC-05 exception 1b / UC-06 step 1: a click counts only inside the drawing. */
export function pointInDrawingArea(p: Point, pageW: number, pageH: number): boolean {
  return centreInDrawingArea({ cx: p.x / pageW, cy: p.y / pageH, w: 0, h: 0 });
}

/**
 * UC-07: the text box for a rectangle drawn around a value read at `angle` — the box at that angle that
 * covers the rectangle (for 0 the rectangle itself; for ±90 its sides swap). Tightening to the digits
 * then shrinks it (UC-07 step 3).
 */
export function boxForDrawnRect(rect: Rect, angle: number): PxBox {
  const a = normalizeAngle(angle);
  const rad = (a * Math.PI) / 180;
  const c = Math.abs(Math.cos(rad));
  const s = Math.abs(Math.sin(rad));
  return { cx: rect.x + rect.w / 2, cy: rect.y + rect.h / 2, w: rect.w * c + rect.h * s, h: rect.w * s + rect.h * c, angle: a };
}

/** Margin around a value's box when deciding what a click hit, as a share of its height. */
const HIT_MARGIN = 0.5;

/** The value whose box (in its own frame, with a small margin) holds the point, if any. */
export function detectionAt(detections: readonly Detection[], p: Point, pageW: number, pageH: number): Detection | null {
  for (const d of detections) {
    const px = toPx(d.box, d.angle, pageW, pageH);
    const { u, v } = axes(px.angle);
    const dx = p.x - px.cx;
    const dy = p.y - px.cy;
    const margin = HIT_MARGIN * px.h;
    if (Math.abs(dx * u.x + dy * u.y) <= px.w / 2 + margin && Math.abs(dx * v.x + dy * v.y) <= px.h / 2 + margin) return d;
  }
  return null;
}

function DrawLayer({ pageW, pageH, scale, onDrawn }: { pageW: number; pageH: number; scale: number; onDrawn: (rect: Rect) => void }) {
  const [drag, setDrag] = useState<{ a: Point; b: Point } | null>(null);
  const toPage = (e: React.PointerEvent<HTMLDivElement>): Point => {
    const r = e.currentTarget.getBoundingClientRect();
    return { x: ((e.clientX - r.left) / r.width) * pageW, y: ((e.clientY - r.top) / r.height) * pageH };
  };
  const shown = drag ? rectFromDrag(drag.a, drag.b) : null;
  return (
    <div
      aria-hidden
      className="absolute inset-0 z-10 cursor-crosshair"
      onPointerDown={(e) => {
        e.currentTarget.setPointerCapture(e.pointerId);
        const p = toPage(e);
        setDrag({ a: p, b: p });
      }}
      onPointerMove={(e) => {
        if (drag) setDrag({ a: drag.a, b: toPage(e) });
      }}
      onPointerUp={(e) => {
        if (!drag) return;
        const rect = rectFromDrag(drag.a, toPage(e));
        setDrag(null);
        onDrawn(rect);
      }}
    >
      {shown ? (
        <div
          className="absolute border-2 border-dashed border-mark bg-mark/10"
          style={{ left: shown.x * scale, top: shown.y * scale, width: shown.w * scale, height: shown.h * scale }}
        />
      ) : null}
    </div>
  );
}

"use client";

import { useEffect, useRef, useState } from "react";
import { useMessages } from "@/messages/client";

/** F-06: rename in the toolbar; the new name is saved with the next Save. */
export function NameField({ name, onRename }: { name: string; onRename: (name: string) => void }) {
  const t = useMessages();
  const r = t.editor.rename;
  const [editing, setEditing] = useState(false);
  const [draft, setDraft] = useState(name);
  const [error, setError] = useState<string | null>(null);
  const input = useRef<HTMLInputElement | null>(null);
  const button = useRef<HTMLButtonElement | null>(null);

    if (editing) input.current?.select();

  function finish(keep: boolean) {
    if (keep) {
      const next = draft.trim();
      if (!next) {
        setError(r.empty);
        return;
      }
      if (next !== name) onRename(next);
    }
    setError(null);
    setEditing(false);
    requestAnimationFrame(() => button.current?.focus());
  }

    return (
      <div className="flex min-w-0 items-center gap-2">
        <h1 className="truncate text-lg font-bold">{name}</h1>

        </button>
      </div>
    );

    <div className="flex items-start gap-2">
      <div>
        <input
          ref={input}
          aria-label={r.label}
          value={draft}
          maxLength={200}
          onChange={(e) => { setDraft(e.target.value); setError(null); }}

### Task 9: Pixel tests (TC-30, TC-31, TC-36)

**Files:**
- Modify: `e2e/support/files.ts` (a dimension line under 16.30), `e2e/support/sheets.ts` (canvas helpers)
- Create: `e2e/pixels.spec.ts`

**Interfaces:**
- Produces (`e2e/support`):
  - `files.ts`: `valuesPdf` also draws a dimension line under "16.30": 0.5 pt thick, 2 pt under the baseline, 30 pt to either side of the value's centre; `DIMENSION_LINE_PX: { x: number; y: number; w: number; h: number }` — its rectangle in pixels of the 300-DPI page (3300 × 2550), computed from the same constants, grown by 2 px on each side
  - `sheets.ts`: `rememberCanvas(page): Promise<{ width: number; height: number }>`; `canvasChanges(page, polygon?: Point[]): Promise<{ changed: number; inside: number; outside: number; angle: number | null }>` (changed pixels since `rememberCanvas`; with a polygon, how many lie inside and outside it; `angle` is the principal direction of the changed pixels in degrees, y down, from their second moments); `maskPolygon(edit: StoredEdit, width: number, height: number): Point[]` (the edit's mask, as the app draws it — digits box plus `max(1, 0.15 × digit height)` — grown by 1.5 px for anti-aliasing)

Why: the editor draws on a canvas, so "the dimension line is left intact" (TC-30), "revert restores the
original pixel for pixel" (TC-31) and "drawn at exactly 58°" (TC-36) can only be proved on its pixels.
The canvas holds the page at its own resolution and is never tainted (it is drawn from a raster), so the
test reads it with `getImageData`.

- [ ] **Step 1: Helpers**

`rememberCanvas` stores `getImageData` of `canvas[role='img']` on `window` and returns its size.
`canvasChanges` compares the current pixels with the stored ones channel by channel (R, G, B), counts
changed pixels, tests each changed pixel centre `(x + 0.5, y + 0.5)` against the polygon (even-odd ray
casting) and accumulates `Σx, Σy, Σx², Σy², Σxy` for the direction:
`angle = ½ · atan2(2·cov(x,y), var(x) − var(y))` in degrees (null when fewer than 2 pixels changed).
All of it runs inside `page.evaluate` (the canvas has 8.4 million pixels).

# M6 Admin Area Implementation Plan

> Work through the tasks in order. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Admin area is complete: S7 Users (list with search, sheets created, grant or revoke Admin,
suspend or reinstate, alongside the existing add-account and issue-password), S8 Access & settings
(permitted domains and emails with the number of accounts each admits, the four system settings),
S9 Audit log (filters, details, CSV in UTF-8 with BOM) and S10 Trash & clean-up (permanent deletion with
typed confirmation, orphan file clean-up).

**Architecture:** The database already enforces every rule (migration 0001): `set_user_role`,
`set_user_status`, `add_allowed`, `remove_allowed`, `set_setting`, `purge_sheet` and `log_maintenance`
check `is_admin()`, refuse the last Admin, self-suspension and self-lockout, range-check settings and write
the audit rows; RLS lets only Admins read the audit log and the access lists. M6 adds no migration. Each
page is a server component that calls `requireAdmin()` and reads with the Admin's session; changes go
through server actions that call `requireAdmin()` again, validate with Zod and call those functions. The
secret key is used only where the design allows it (NFR-10): deleting a purged sheet's files and listing
and deleting orphan folders. Pure modules hold the audit filter, the CSV format, orphan selection and
the purge sequence, so the risky parts are unit-tested.

**Tech Stack:** Next.js 16.3.8 (server components, server actions, a route handler for the CSV), React
19.2, Tailwind CSS 4, Supabase (`@supabase/ssr` with the Admin's session; the secret-key client for files
only), Zod 4, Vitest 4, Playwright 1.63.

**Spec:** `docs/design/spec-sheet-editor-design.md` — UC-13 – UC-18, BR-08, BR-13 – BR-17, F-20 – F-30,
NFR-02, NFR-06 (Admin area needs ≥ 1024 px), NFR-07, NFR-09, NFR-10, section 2.5, Table B.1; test cases
TC-55, TC-58, TC-62 – TC-64, TC-66 – TC-68, TC-72, TC-74 – TC-76 (TC-56, 57, 59, 60, 61, 65, 69, 70, 71,

## Global Constraints

- Repo is **public**: never commit `.env.local`, real sheets, SO/MO numbers, passwords or keys. Stage files one by one (`git add <path>`), never `git add -A` or `git add .`.
- File names, commit messages and documents are in English. The only Vietnamese text in the repository is interface copy in `src/messages/vi.ts` (end-to-end tests may match Vietnamese interface text in regular expressions).
- Commits carry no attribution trailer of any kind (no Co-Authored-By, no tool or AI mentions).

- Every Admin page, server action and route handler calls `requireAdmin()` itself (NFR-02: interface, server and database each check). Anyone else gets "Not found" (the existing Admin layout).
- NFR-10: the secret-key client (`createSupabaseAdmin`) is used only to delete a purged sheet's files and to list and delete orphan folders (besides its existing uses for accounts). Everything else runs in the Admin's own session, so RLS and the database functions apply and the audit rows name the Admin.
- No migration in M6; applied migrations are never edited.
- Times are shown in `Asia/Ho_Chi_Minh`.
- Table B.1 messages: "At least one active admin must remain." · "You cannot suspend your own account." · "This change would lock you out of the system." · "{n} accounts will lose access. Continue?" · "The value must be between {min} and {max}." · "Too many results. Narrow the time range and try again." · "'{name}' was permanently deleted. / Deletion did not finish. Try again." · "No orphan files." UC-14: "This entry is already on the list." UC-17: "This sheet is no longer in the Trash."
- Settings ranges (UC-15): maximum file size 1–50 MB (default 20); low-resolution warning 800–5000 px (default 2000); template ratio tolerance 0.5–5 % (default 2); download link lifetime 1–60 minutes (default 10).
- Audit log (UC-16): first view = the latest 100 entries of the past 7 days; filters: time range, person, action group, sheet id; CSV = exactly the current filter, UTF-8 with BOM, at most 50,000 rows.
- Permanent deletion (UC-17, BR-16): only sheets in the Trash; the delete button is enabled only when the retyped name matches exactly; files first (secret key), then `purge_sheet` with the Admin's session; a file failure keeps the record and a retry deletes whatever remains.
- Orphan clean-up (UC-18): storage folders with no matching record, older than 24 hours; logged with `log_maintenance(folders, bytes)`.
- The Admin area needs a window at least 1024 px wide (NFR-06); below that it shows a notice.
- End-to-end tests always have timeouts, run against the development project only (`E2E_DEV_PROJECT_REF` guard, HTTPS only), restore every setting, role, status and access entry they change, clean up what they create and use only reserved test accounts (`e2e-staff@ctyhp.vn`, `e2e-staff-b@ctyhp.vn`, and the new `e2e-admin@ctyhp.vn`).

```ts
const TIME_ZONE = "Asia/Ho_Chi_Minh";
const DAY = /^\d{4}-\d{2}-\d{2}$/;
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export const AUDIT_GROUPS = ["all", "auth", "sheet", "user", "access", "settings", "maintenance"] as const;
export type AuditGroup = (typeof AUDIT_GROUPS)[number];
export type AuditFilter = { from: string; to: string; actor: string | null; group: AuditGroup; target: string | null };

/** "YYYY-MM-DD" of `date` in Ho Chi Minh City. */
function localDay(date: Date): string {
  return new Intl.DateTimeFormat("en-CA", { timeZone: TIME_ZONE, year: "numeric", month: "2-digit", day: "2-digit" }).format(date);
}

function addDays(day: string, n: number): string {
  const d = new Date(`${day}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + n);
  return d.toISOString().slice(0, 10);
}

function validDay(v: string | undefined): string | null {
  if (!v || !DAY.test(v)) return null;
  return new Date(`${v}T00:00:00Z`).toISOString().slice(0, 10) === v ? v : null;
}

/** UC-16 step 1–2: the filter from the URL, defaulting to the last 7 days and every action. */
export function parseAuditFilter(params: Record<string, string | undefined>, now: Date): AuditFilter {
  const today = localDay(now);
  let from = validDay(params.from) ?? addDays(today, -6);
  let to = validDay(params.to) ?? today;
  if (from > to) [from, to] = [to, from];
  const group = (AUDIT_GROUPS as readonly string[]).includes(params.group ?? "") ? (params.group as AuditGroup) : "all";
  const actor = params.actor && UUID.test(params.actor) ? params.actor.toLowerCase() : null;
  const target = params.target && UUID.test(params.target) ? params.target.toLowerCase() : null;
  return { from, to, actor, group, target };
}

/** Whole local days: from 00:00 on `from` to 00:00 the day after `to` (UTC+07:00, no daylight saving). */
export function auditRange(filter: AuditFilter): { fromIso: string; toIsoExclusive: string } {
  return { fromIso: `${filter.from}T00:00:00+07:00`, toIsoExclusive: `${addDays(filter.to, 1)}T00:00:00+07:00` };
}

export function groupPrefix(group: AuditGroup): string | null {
  return group === "all" ? null : `${group}.`;
}

export function filterQuery(filter: AuditFilter): string {
  const q = new URLSearchParams({ from: filter.from, to: filter.to });
  if (filter.actor) q.set("actor", filter.actor);
  if (filter.group !== "all") q.set("group", filter.group);
  if (filter.target) q.set("target", filter.target);
  return q.toString();
}
```

`src/admin/csv.ts`:

```ts
export const CSV_BOM = "﻿";

/** One CSV cell: quoted when needed, quotes doubled, and a leading ' when a spreadsheet would run it as a formula. */
export function csvCell(value: string | number | null): string {
  if (value === null) return "";
  let s = String(value);
  if (/^[=+\-@\t\r]/.test(s)) s = `'${s}`;
  return /[",\r\n]/.test(s) ? `"${s.replace(/"/g, '""')}"` : s;
}

export function csvLine(values: readonly (string | number | null)[]): string {
  return values.map(csvCell).join(",");
}

export type AuditCsvRow = {
  occurredAt: string;
  actorEmail: string | null;
  action: string;
  targetType: string | null;
  targetId: string | null;
  detail: unknown;
};

/** UC-16 step 4: UTF-8 with a BOM so Excel shows Vietnamese correctly; CRLF line ends. */
export function auditCsv(rows: readonly AuditCsvRow[]): string {
  const lines = [csvLine(["occurred_at", "actor_email", "action", "target_type", "target_id", "detail"])];
  for (const r of rows) {
    lines.push(csvLine([r.occurredAt, r.actorEmail, r.action, r.targetType, r.targetId, JSON.stringify(r.detail ?? {})]));
  }
  return CSV_BOM + lines.join("\r\n") + "\r\n";
}
```

```ts
const SHEET_ID = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/;

export const ORPHAN_MIN_AGE_HOURS = 24;

/** A top-level folder of the `spec-sheets` bucket: its newest object's time, total size and object paths. */
export type StorageFolder = { name: string; newestAt: string; bytes: number; paths: string[] };

/**
 * UC-18 step 2: folders named like a sheet id with no sheet record, whose newest file is at least
 * `minAgeHours` old (an upload in progress writes its files before its record, design 5.3).
 */
export function findOrphans(folders: readonly StorageFolder[], recordIds: ReadonlySet<string>, now: Date, minAgeHours = ORPHAN_MIN_AGE_HOURS): StorageFolder[] {
  const cutoff = now.getTime() - minAgeHours * 3_600_000;
  return folders.filter((f) => SHEET_ID.test(f.name) && !recordIds.has(f.name) && new Date(f.newestAt).getTime() <= cutoff);
}
```

`src/admin/purge.ts`:

```ts
export type PurgeSteps = {
  load(id: string): Promise<{ name: string; paths: string[]; inTrash: boolean } | null>;
  removeFiles(paths: string[]): Promise<boolean>;
  purgeRecord(id: string): Promise<"ok" | "not_in_trash" | "failed">;
};

export type PurgeResult = "ok" | "not_found" | "not_in_trash" | "name_mismatch" | "files_failed" | "failed";

/**
 * UC-17 step 3 (BR-16): only a sheet in the Trash, only with its exact name retyped; the files go first,
 * so a failure there keeps the record (and the sheet in the Trash) and a retry removes whatever remains.
 */
export async function purgeSequence(steps: PurgeSteps, id: string, typedName: string): Promise<PurgeResult> {
  const sheet = await steps.load(id);
  if (!sheet) return "not_found";
  if (!sheet.inTrash) return "not_in_trash";
  if (typedName !== sheet.name) return "name_mismatch";
  if (!(await steps.removeFiles(sheet.paths))) return "files_failed";
  return steps.purgeRecord(id);
}
```
